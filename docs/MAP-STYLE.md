# Eksperymentalny jasny styl mapy

Osobny commit zmienia wyłącznie wygląd mapy. Źródłem pozostają kafelki OpenStreetMap; lekko obniżone nasycenie i rozjaśniona paleta pomagają odróżnić zieloną trasę i kolorowe atrakcje. Nazwy, ścieżki oraz wymagane oznaczenie OSM pozostają widoczne. To lokalna zmiana kolorystyki, nie nowy dostawca ani mapa wektorowa.

Przycisk **Jasna / OSM** przełącza styl bez kasowania planu. Można też cofnąć cały commit stylu przez `git revert`, zachowując poprzedni commit z naprawą tras.

Sprawdzono również CARTO Voyager jako potencjalny nowy podkład, ale aktualny serwis wymaga osobnego klucza. Nie podłączono niezarejestrowanego dostępu: https://carto.com/blog/new-voyager-basemap/index.html .
